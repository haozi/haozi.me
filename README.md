# haozi.me

Two sites in a trench coat:

- `/` — a deliberately ridiculous, late-90s/early-2000s Chinese personal site.
  Marquee, ActiveX prompt, PHP warning, popup ad, mojibake guestbook, blinking
  title, slow-loading canvas portrait, the works.
- `/blog`, `/archive`, `/tags`, `/categories` — a calm, modern, long-form blog.

Both halves are statically generated by Next.js at build time. There is no
server.

## Stack

- **Next.js 16** (App Router) with `output: "export"` for full static export.
- **TypeScript**, **Tailwind CSS v4** (CSS-first config in `globals.css`).
- **MDX** content via `next-mdx-remote/rsc` — posts live in `content/posts/`.
- **rehype-pretty-code + shiki** for syntax highlighting at build time.
- **rehype-slug + rehype-autolink-headings** for stable heading anchors.
- **gray-matter** for frontmatter, **reading-time** for read estimates.
- **feed** for RSS, Next's built-in `sitemap.ts` / `robots.ts` for those.

## Adding a post

1. Create `content/posts/<slug>.mdx`:

```mdx
---
title: 文章标题
date: 2026-04-25
description: 一句话摘要。
tags: [tag1, tag2]
category: 工程
---

正文…
```

2. `npm run dev` — the post appears at `/blog/<slug>`, in the index,
   in the archive, and in the appropriate tag/category pages automatically.

Frontmatter fields:

| field         | required | notes                                                  |
| ------------- | :------: | ------------------------------------------------------ |
| `title`       |    ✓     | string                                                 |
| `date`        |    ✓     | ISO `yyyy-mm-dd`                                       |
| `updated`     |          | optional; surfaced in OG `modifiedTime` and sitemap    |
| `description` |          | shown in the list / cards and used as `<meta>` desc    |
| `tags`        |          | string[]                                               |
| `category`    |          | string; falls back to "未分类"                         |
| `draft`       |          | true → hidden in production                            |
| `cover`       |          | reserved for future OG image generation                |
| `toc`         |          | set `false` to hide the on-page TOC sidebar            |

## Scripts

```bash
npm run dev         # local dev server
npm run lint        # eslint
npm run typecheck   # tsc --noEmit
npm run build       # builds search index, then static export → out/
npm run format      # prettier
```

`npm run build` writes the static site to `out/`. Drop that on any static
host (Netlify, Cloudflare Pages, GitHub Pages, S3+CloudFront, …).

## Constraints (read these before changing things)

See `AGENTS.md` and `DECISIONS.md`. Short version:

- The retro homepage stays retro. Don't sand its edges off.
- Blog pages stay calm. Don't bleed retro effects into article bodies.
- SSG only. Anything that breaks `output: "export"` is out.
- No CMS, no DB, no paid services without an explicit decision entry.
