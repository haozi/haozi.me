终于把 haozi.me 重写了一遍。

**前因**：原来的站是几年前手撸的一个静态页，HTML/CSS 混在一起，里面还埋着我自己写来玩的 PHP warning、ActiveX 弹窗、xss payload 之类的彩蛋。久而久之，加文章这件事变得越来越烦。

**现在**：

- 首页保留原汁原味的「上世纪个人站」精神。
- 博客部分整个是现代的 — Next.js 16 + App Router + MDX + Tailwind，纯静态生成。
- 一切内容都在 `content/posts/*.mdx`，提交即发布。

下面顺便测一下 markdown 各种元素能不能正常渲染。

## 标题二级

这是一段普通的文字。后面跟一个**加粗**和一个 _斜体_，再来一个 [外链](https://nextjs.org)。

## 代码块

来一段 TypeScript：

```ts
type Post = {
  slug: string;
  title: string;
  date: string;
};

export function byDate(a: Post, b: Post): number {
  return new Date(b.date).getTime() - new Date(a.date).getTime();
}
```

来一段 bash：

```bash
pnpm dlx create-next-app@latest --typescript --tailwind --app
```

行内代码 `const x = 1;` 应该有自己的样式。

## 表格

| 项目 | 选型               | 备注              |
| ---- | ------------------ | ----------------- |
| 框架 | Next.js 16         | App Router + SSG  |
| 样式 | Tailwind CSS v4    | 含 typography 插件 |
| 内容 | MDX + gray-matter  | frontmatter 驱动   |
| 高亮 | rehype-pretty-code | 双主题             |

## 图片

页面里所有图片都走 `next/image`，但因为是 `output: "export"`，关掉了内置 optimizer。
